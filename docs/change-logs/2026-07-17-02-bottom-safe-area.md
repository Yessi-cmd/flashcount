# 底部固定控件安全区修复

## 目的

修复报表等主页面的滚动内容被自定义底部标签栏覆盖的问题，并消除账本批量操作栏、删除撤销提示与交易内容及主标签栏之间的同类遮挡。

## 影响文件

- `FlashCount/Views/MainTabView.swift`
- `FlashCount/Views/Ledger/LedgerView.swift`
- `FlashCount/Views/Report/ReportView.swift`
- `FlashCount/FlashCountApp.swift`
- `FlashCountUITests/FlashCountSmokeTests.swift`
- `docs/change-logs/2026-07-17-02-bottom-safe-area.md`

## 行为变化

- 自定义主标签栏从覆盖层改为与主页面上下并列布局，账本、预算、报表和资产页的可用高度会直接扣除底栏真实高度。
- 报表滚动到底时，最后一张“智能洞察”卡片可完整停在标签栏上方。
- 账本批量操作栏和删除撤销提示也改为安全区 inset；显示期间会为交易列表预留空间，并自然叠放在主标签栏上方。
- 增加仅在 Debug 测试参数下启用的幂等报表数据夹具，以及报表末尾、账本批量操作栏与主标签栏不相交的 UI 回归测试。

## 验证

- XcodeBuildMCP 在 iPhone 17 Pro（iOS 26.2）模拟器上的 Debug 构建通过，无警告或错误。
- 定向报表遮挡回归测试通过：完整报表滚动到底后，Debug 末尾锚点位于主标签栏上方。
- 定向账本遮挡回归测试通过：批量操作栏的“完成”按钮位于主标签栏上方。
- 原有底栏对齐与快捷记账入口定向测试通过，底栏结构调整后五个控件的位置、尺寸和选中态保持稳定。
- 完整测试套件在加入账本定向断言前通过：`90` 项通过、`0` 项失败、`0` 项跳过；新增账本定向断言随后单独通过。
- 在 iPhone 17 Pro（iOS 26.2）模拟器中生成完整周报并滚动到底截图检查，“智能洞察”整卡与底栏之间保留明确间距。
- `git diff --check` 通过。

## 剩余限制

- 删除撤销提示出现时会短暂收缩账本的可滚动区域，以保证提示不遮挡交易内容；提示消失后布局恢复。
