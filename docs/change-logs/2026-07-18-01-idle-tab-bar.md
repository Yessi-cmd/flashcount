# 空闲自动隐藏底部标签栏

## 目的

在用户长时间没有操作时收起底部标签栏，减少报表、账本等长内容页面的视觉占用；用户再次触控页面时自动唤回。

## 影响文件

- `FlashCount/Views/MainTabView.swift`
- `FlashCountUITests/FlashCountSmokeTests.swift`
- `docs/change-logs/2026-07-18-01-idle-tab-bar.md`

## 行为变化

- 主标签栏默认在 10 秒无触控或滚动后淡出并移出布局，页面内容获得完整底部高度。
- 任意页面点击、滚动、切换 Tab 或点击快捷记账都会立即唤回标签栏并重新计时。
- 弹窗、引导页和 App 非活跃期间不会让隐藏计时干扰前台交互；回到前台后标签栏恢复可见并重新计时。
- Debug UI 测试可使用更短的空闲时长验证隐藏与唤回，不影响正式版本。

## 验证

- XcodeBuildMCP 在 iPhone 17 Pro（iOS 26.2）模拟器上的 Debug 构建通过，无警告或错误。
- 新增空闲隐藏/点击唤回 UI 测试通过。
- 原有底栏对齐、报表底部防遮挡、快捷记账和账本批量操作栏定向测试全部通过。
- 完整测试套件通过：`92` 项通过、`0` 项失败、`0` 项跳过。
- 在模拟器中等待超过测试空闲阈值后截图确认标签栏实际消失，页面底部空间被释放。
- `git diff --check` 通过。

## 剩余限制

- 空闲计时目前固定为 10 秒，没有在设置中提供用户自定义入口。
