# 版本 1.4.0

## 目的

为周期补账与现金流预测功能发布新的 minor 版本，并同步递增构建号。

## 影响文件

- `project.yml`：将营销版本从 `1.3.0` 更新为 `1.4.0`，构建号从 `3` 更新为 `4`。
- `FlashCount.xcodeproj/project.pbxproj`：由 XcodeGen 根据 `project.yml` 重新生成。

## 行为变化

- App 及后续 IPA 的版本标识变为 `1.4.0 (4)`。

## 验证

- `xcodegen generate` 成功。
- Release arm64 AltStore 打包脚本完成构建与产物校验。
- 已确认 `Info.plist` 中的版本标识为 `1.4.0 (4)`。

## 仍有限制

- 本次只调整版本元数据，不改变业务逻辑或数据模型。
