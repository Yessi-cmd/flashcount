# 默认提交至 main

## 目的

建立清晰的分支约定，避免短期开发分支在仓库中长期累积。

## 影响文件

- `AGENTS.md`
- `docs/change-logs/2026-07-25-11-main-default-branch.md`

## 行为变化

- `main` 是默认且唯一的长期分支；日常工作直接提交至 `main`。
- 仅在高风险重构或并行工作等确有隔离需求时创建临时分支；合并至 `main` 后应及时删除本地及远端分支。

## 验证结果

- 已检查 `AGENTS.md` 中的分支规则及本变更日志，确认内容和文件命名符合项目约定。

## 剩余限制

- 本次仅建立后续工作约定，未清理现有本地或远端分支；清理前仍需逐一确认未合并提交。
