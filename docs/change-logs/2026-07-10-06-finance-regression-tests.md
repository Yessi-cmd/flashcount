# Finance regression tests

## Purpose

Add a first automated regression suite for the high-risk financial calculations and recurring-entry idempotency.

## Affected files

- `FlashCountTests/FinanceDomainTests.swift`
- `project.yml`

## Coverage

- Month-end payday clamping.
- Projected budget overrun alerting.
- Re-running recurring processing does not add a second transaction for an already advanced due date.

## Verification

The `FlashCountTests` target is generated by XcodeGen. Test execution is pending because the local CoreSimulator service has no available runtimes.
