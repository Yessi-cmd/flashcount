# 分类子菜单即时响应

## 目的

消除点按含子类的大类后，分类圆盘在展开动画完成前不可操作造成的迟滞感；保留轻量的视觉反馈和既有分类选择方式。

## 影响文件

- `FlashCount/Views/Components/CategoryPickerComponents.swift`
- `FlashCountUITests/FlashCountSmokeTests.swift`
- `docs/change-logs/2026-07-12-09-category-menu-instant-response.md`

## 行为变化

- 分类圆盘在加入界面时立即接收点按、拖动和无障碍选择，不再等待原先约 280ms 的展开完成。
- 圆盘和子类标签统一使用约 120ms 的淡入、缩放过渡；保留来源位置的轻微位移反馈，不增加旋转。
- 选中后的 90ms 确认反馈和收起动画保持不变，快速选择仍会提供清晰的确认感。
- 快速记账、编辑账目和周期账单继续复用同一分类圆盘，因此同步获得该响应优化。

## 验证

- 新增 UI 冒烟覆盖：点按“餐饮”后不等待菜单动画完成，立即点按“正餐”，并确认表单回填且圆盘关闭。
- 运行分类圆盘相关单元测试与快速记账 UI 测试。

## 剩余限制

- 模拟器和 UI 自动化无法准确衡量真实设备触控与触觉马达的主观手感；应在真机连续执行“大类 → 子类”快速点按和拖动拨选作最终确认。
