# Back Tap Quick Entry

## Purpose

Make FlashCount's existing quick-entry App Shortcut easy to discover and
configure as the iOS double Back Tap action, so users can reach the amount
entry screen with two taps on the back of the device.

## Affected Files

- `FlashCount/Core/QuickAddIntent.swift`
- `FlashCount/FlashCountApp.swift`
- `FlashCount/Views/Ledger/LedgerView.swift`
- `FlashCount/Views/MainTabView.swift`
- `FlashCount/Views/Onboarding/OnboardingView.swift`
- `FlashCount/Views/Settings/BackTapSetupView.swift`
- `FlashCount/Views/Settings/SettingsView.swift`
- `FlashCountTests/AppRoutingTests.swift`
- `FlashCountUITests/FlashCountSmokeTests.swift`
- `FlashCount.xcodeproj/project.pbxproj` (regenerated by XcodeGen)
- `docs/change-logs/2026-07-24-02-back-tap-quick-entry.md`

## Behaviour Changes

- FlashCount refreshes its App Shortcut registration during app startup.
- Settings now contains a dedicated “轻点背面快速记账” guide with a system
  Shortcuts link and the exact iOS setup path.
- Running the “快速记账” shortcut opens FlashCount and presents quick entry.
- A pending quick-entry request is consumed exactly once, avoiding repeated
  presentation after later app activations.
- The onboarding guidance now describes the full Back Tap setup path.
- Settings and setup controls expose stable accessibility labels and
  identifiers for navigation and UI testing.

## Remaining Limitations

- iOS does not allow an app to assign the Back Tap action automatically. Each
  user must select FlashCount's “快速记账” shortcut once in
  Settings > Accessibility > Touch > Back Tap > Double Tap.
- The physical double-tap gesture cannot be exercised in Simulator; automated
  coverage verifies shortcut routing and setup discoverability separately.
